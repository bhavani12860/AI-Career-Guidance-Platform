01

What are Data Structures?

A data structure is a way of organizing and storing data so that it can be accessed and modified efficiently.

Key Idea

Good data structures help programs store, search, insert, delete and process data efficiently.

02

Types of Data Structures

Data structures are commonly divided into two major categories.

  • Linear: Array, Linked List, Stack and Queue
  • Non-Linear: Tree and Graph
03

Array

An array stores multiple elements in a contiguous sequence of memory. 

int numbers[] = {10, 20, 30, 40, 50};

Important Points

  • Elements are accessed using indexes.
  • Index usually starts from 0.
  • Fast random access.
04

Linked List

A linked list consists of nodes where each node contains data and a reference to another node.

Common Types

Singly Linked List, Doubly Linked List and Circular Linked List.

05

Stack

Stack follows the LIFO principle.

LIFO = Last In, First Out

The last element inserted into the stack is removed first.

Applications

  • Function calls
  • Undo operations
  • Expression evaluation
  • Browser history
06

Queue

Queue follows the FIFO principle.

FIFO = First In, First Out

The first element inserted is removed first.

Applications

  • Printer queues
  • CPU scheduling
  • Task processing
07

Tree

A tree is a non-linear data structure consisting of nodes connected by edges.

  • Root
  • Parent
  • Child
  • Leaf
  • Subtree
Common Tree

Binary Tree and Binary Search Tree are frequently asked in interviews.

08

Graph

A graph consists of vertices and edges used to represent relationships between different entities.

Common Applications

Social networks, maps, network routing and recommendation systems.

09

Hash Table

A hash table stores data using key-value relationships. 

{
    "name": "Bhavani",
    "role": "Developer"
}

Hashing is commonly used for fast lookup operations.

10

Time & Space Complexity

Complexity helps us understand how efficiently an algorithm uses time and memory.

O(1) Constant
O(log n) Logarithmic
O(n) Linear
O(n²) Quadratic

  6. What is a Binary Search Tree?
  7. What is Big-O notation?
